Sada Platform API Documentation

Complete reference for Sada's Social Listening, AI Sentiment Analytics Microservice, and Multi-tenant Workspace API (V1).

Base URL: http://127.0.0.1:8000/api/v1 Format: JSON Auth: Sanctum Bearer Token

🔑 Authentication & Headers

All protected endpoints require a valid Sanctum Bearer token in the Authorization HTTP header. Multi-tenant endpoints automatically use your active tenant context or can specify X-Tenant-ID.

Authorization: Bearer 1|NlltBWufci3a9nBEooiFpcIcy7LY3VBdVc2BvLgfd3dbdc69 Content-Type: application/json Accept: application/json X-Tenant-ID: 1
1 Authentication & User Profile
POST /auth/register
Register a new user account and automatically provision a default tenant workspace.
Request Payload
{ "name": "Ehab Asker", "email": "ehab@example.com", "password": "Password123!", "password_confirmation": "Password123!", "company_name": "Sada Intelligence" }
POST /auth/login
Authenticate existing credentials and issue a new Sanctum Bearer API token.
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/auth/login' \ --header 'Content-Type: application/json' \ --header 'Accept: application/json' \ --data '{ "email": "admin@tenant1.com", "password": "password" }'
GET /me
Retrieve profile information for the currently authenticated user and active workspace.
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/me' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN'

3 Keywords & AI Social Listening
GET /keywords
Retrieve all registered brand/topic keywords monitored by the active tenant workspace.
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/keywords' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN'
POST /keywords
Add a new keyword to active tenant monitoring list.
Request Payload
{ "name": "الذكاء الاصطناعي", "priority": "high", "match_type": "contains", "language": "ar" }
POST /keywords/trigger-scrape
Trigger async keyword scraping & AI sentiment analytics. If keywords array is omitted, it automatically scrapes all active keywords registered for the tenant across Instagram, Facebook, X (Twitter), and TikTok.
Request Payload (Custom Keywords & Country)
{ "keywords": ["الذكاء الاصطناعي", "الرياض"], "platforms": ["instagram", "facebook", "x", "tiktok"], "country": "Saudi Arabia" }
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/keywords/trigger-scrape' \ --header 'Content-Type: application/json' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN' \ --data '{ "platforms": ["instagram", "facebook", "x", "tiktok"], "country": "Saudi Arabia" }'

7 Topic Trends Discovery & AI Analysis
POST /trends/analyze
Trigger AI-powered trend discovery for any industry or topic. Generates relevant keywords/hashtags, scrapes posts across Facebook, Instagram, TikTok, and Twitter (SA/EG) with customizable limits (e.g. 50, 100, 250+ posts), and clusters them into major trends with sentiment classification, summaries, actionable crisis solutions, and marketing strategies.

Queue Execution (Default): Returns HTTP 202 Accepted with a task ID. The scraping job runs in the background. Poll GET /trends/{id} for completed results.
Request Payload Parameters
• topic (string, required): The target industry or topic (e.g. "الذكاء الاصطناعي في التعليم", "Fintech in Saudi Arabia").
• limit (integer, optional, default: 50): Number of posts to scrape per platform (supports 10, 50, 100, 250, up to 500).
• platforms (array, optional): Target platforms (e.g. ["facebook", "instagram", "tiktok", "twitter"]).
• sync (boolean, optional, default: false): If true, runs synchronously (requires high server timeout).
cURL Example (Queue Dispatched)
curl --location 'http://127.0.0.1:8000/api/v1/trends/analyze' \ --header 'Content-Type: application/json' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN' \ --data '{ "topic": "الذكاء الاصطناعي في التعليم", "limit": 100, "platforms": ["facebook", "instagram", "tiktok", "twitter"] }'
Response Sample (202 Accepted)
{ "success": true, "message": "Trend discovery task queued successfully.", "data": { "id": 1, "topic": "الذكاء الاصطناعي في التعليم", "status": "pending", "limit": 100, "platforms": ["facebook", "instagram", "tiktok", "twitter"], "keywords": null, "hashtags": null, "raw_data_count": 0, "trends_count": 0, "trends_analysis": null, "error_message": null, "created_at": "2026-09-11T00:00:00.000000Z", "updated_at": "2026-09-11T00:00:00.000000Z" } }

GET /trends
List all historical topic trend analyses performed within the active workspace with search and pagination.
Query Parameters
• search (optional): Filter topics by search keyword.
• status (optional): Filter by status (pending, processing, completed, failed).
• per_page (optional, default: 15): Number of items per page.
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/trends?per_page=10' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN'
