1. Keywords Management

POST /api/v1/keywords
Add a new keyword to the current active tenant monitoring list.
Request Payload
{ "name": "الذكاء الاصطناعي", "priority": "high", "match_type": "contains", "language": "ar" }
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/keywords' \ --header 'Content-Type: application/json' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN' \ --data '{ "name": "الذكاء الاصطناعي", "priority": "high", "match_type": "contains", "language": "ar" }'
GET /api/v1/keywords
Retrieve all registered keywords for the current active tenant.
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/keywords' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN'

2. Analytics by Keywords (Social Listening)

POST /api/v1/keywords/trigger-scrape
Trigger async keyword scraping & AI sentiment analytics. If keywords array is empty or omitted, it automatically fetches all active keywords registered for the tenant. Optional country parameter filters posts by region (e.g., "Saudi Arabia").
Request Payload (Option A: Auto-use Tenant Keywords)
{ "platforms": ["instagram", "facebook", "x", "tiktok"], "country": "Saudi Arabia" }
Request Payload (Option B: Explicit Keywords)
{ "keywords": ["الذكاء الاصطناعي", "الرياض"], "platforms": ["instagram", "facebook", "x", "tiktok"], "country": "Saudi Arabia" }
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/keywords/trigger-scrape' \ --header 'Content-Type: application/json' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN' \ --data '{ "platforms": ["instagram", "facebook", "x", "tiktok"], "country": "Saudi Arabia" }'
GET /api/v1/articles
Fetch scraped posts/articles along with their sentiment analytics. Filterable by source, language, and search terms.
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/articles' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN'

3. Analytics by Post Link (Comments & Sentiment)

POST /api/v1/comments/scrape
Receive post URLs across social media platforms, scrape comments, perform AI sentiment analysis, and save them.
Request Payload
{ "insta_urls": ["https://www.instagram.com/p/ExamplePost/"], "facebook_urls": [], "tiktok_urls": [], "twitter_urls": [] }
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/comments/scrape' \ --header 'Content-Type: application/json' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN' \ --data '{ "insta_urls": ["https://www.instagram.com/p/ExamplePost/"] }'
GET /api/v1/comments
Fetch stored comments along with their extracted sentiment (positive, negative, neutral) and sentiment score.
cURL Example
curl --location 'http://127.0.0.1:8000/api/v1/comments' \ --header 'Accept: application/json' \ --header 'Authorization: Bearer YOUR_BEARER_TOKEN'
